Roblox merupakan game yang terkenal di seluruh dunia. Roblox sangat terkenal dikarenakan terdapat banyak sekali game - game yang dimulai dari game berkebun hingga game perang.

Alasan saya memilih game ini, karena game ini menjadi satu-satunya game yang saya mainkan pada saat saya sendiri.Salah satu gamenya yaitu, Tower Defense Simulator (TDS) yang bisa dimainkan sebanyak 4 player.

Digame tersebut, kita diharuskan menyusun strategi dalam mempertahankan wilayah kita dari zombie. Adapun game lain seperti AOT Revolution yang mengarahkan pemain untuk membunuh titan dan masih banyak lagi.

Game ini sangat cocok untuk dimainkan bersama teman-teman. Kita bisa tertawa bersama, tegang bersama, saling jahil, dan lain-lain. Pengalaman yang paling sering didapat ialah tertawa bersama karena hampir setiap game pasti ada momen lucu.

Device yang saya gunakan untuk memainkan game roblox adalah laptop. Mengapa laptop bukan hp? Karena HP saya yang kurang bagus atau kasarnya "Kentang". Ssetelah saya berada di kelas 10, saya membeli laptop dan saya bisa bermain roblox dengan pengalaman yang lebih baik.

Biasanya, saya bermain roblox selama 2 - 4 jam. Saya memainkan game ini pada saat malam hari setelah tugas saya sudah saya kerjakan dan saya tidak tau harus ngapain.

Kesimpulannya, Roblox ini menjadi salah satu game favorit saya dan sangat cocok dimainkan pada saat memiliki waktu luang bersama teman.
